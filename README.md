Overview
--------

Contemporary Open Learning Creator is a powerful SaaS platform designed for educators and organisations to create, manage, and deliver interactive educational content. You can build multi-page courses, design engaging assessments like MCQs and true/false questions, and organise documentation spaces efficiently. The platform emphasises transformative pedagogy, shifting from traditional didactic methods to technology-mediated, authentic student learning experiences.

  

With tools for uploading HTML presentations, Keynote zips, and rich text editing (bold, italic, lists, alignments), you streamline content creation. Access your dashboard at https://app.contemporarylearninghub.co.za/creator.html to get started.

Key features

**Interactive Course Builder**

Create multi-page courses with components like MCQ editors, true/false questions, and external links. Supports rich formatting and alignment options.

**Content Uploads**

Easily upload HTML files, Mac Keynote ZIPs, or presentations. Convert them into interactive modules seamlessly.

  

**Transformative Tools**

Leverage pedagogy-focused features for authentic learning, including statement builders and visual editors.
